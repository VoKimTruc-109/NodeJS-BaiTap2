## 2. Nội dung bài tập

Tạo ứng dụng Node.js sử dụng module `http`.

- Server chạy tại cổng 3000.
- Khi truy cập trang chủ, server trả về nội dung HTML.
- Trang web hiển thị họ tên và mã sinh viên.

## 3. Công nghệ sử dụng

- Node.js
- JavaScript
- Module HTTP có sẵn trong Node.js
- Visual Studio Code

## 4. Cách chạy chương trình

**Bước 1:** Mở thư mục chứa file `serverr.js` bằng Visual Studio Code.

**Bước 2:** Mở Terminal tại thư mục dự án.

**Bước 3:** Nhập lệnh chạy chương trình:

```bash
node serverr.js
```

**Bước 4:** Khi chạy thành công, Terminal hiển thị:

```text
Server đang chạy tại http://localhost:3000
```

**Bước 5:** Mở trình duyệt và truy cập địa chỉ:

```text
http://localhost:3000
```

**Bước 6:** Quan sát kết quả trang web hiển thị họ tên và mã sinh viên.
